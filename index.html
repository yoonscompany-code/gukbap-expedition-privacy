국밥원정대 개인정보처리방침

시행일자: 2026년 8월 16일 (최초 시행 2026년 8월 4일 / 개정)

윤스컴퍼니(이하 "회사")는 국밥원정대 앱(이하 "서비스") 이용자의 개인정보를 소중히 다루며, 아래와 같이 처리하고 있습니다.

1. 수집하는 정보 및 수집 방법

자동으로 생성·수집되는 정보

  • 고유 사용자 식별자(UUID): 서비스는 별도의 회원가입(이메일·비밀번호 입력) 없이, 앱을 처음 실행하면 Supabase 인증 시스템이 자동으로 발급하는 익명 사용자 식별자(UUID)를 사용합니다. 이름, 전화번호, 이메일 등 개인 식별정보를 직접 수집하지 않습니다.
  • 위치정보(GPS): "내 주변" 기능을 사용할 때만 수집되며, 가까운 국밥집을 계산하는 데 기기 내에서만 사용되고 서버로 전송·저장되지 않습니다.
  • 오류(크래시) 발생 시 기기 정보: 앱 오류가 발생하면 오류 분석을 위해 기기 모델, OS 버전, 앱 버전, 오류 내용이 오류 리포팅 서비스(Sentry)로 전송됩니다. 이 과정에서 요청 처리상 IP 주소가 전달될 수 있으나, 닉네임 등 계정을 특정할 수 있는 정보는 별도로 전송하지 않습니다.
  • IP 주소: 방문 기록·후기·맛집 제보·문의·신고를 등록할 때 부정 이용(어뷰징) 방지와 비정상적인 접근 차단, 법적 분쟁 발생 시 확인 목적으로 서버에 자동 기록됩니다. 앱 화면에는 노출되지 않으며, 별도 목적으로 이용하지 않습니다.

이용자가 직접 입력하는 정보

  • 닉네임
  • 저장한 국밥집 목록
  • 방문 기록
  • 별점 및 한줄 후기
  • 고객센터 문의 내용
  • 신고 내용

이용자의 별도 동의(권한 허용)가 있는 경우에만 수집되는 정보

  • 푸시 알림 토큰: 설정 화면에서 알림 권한을 허용한 경우에만 생성되어 저장됩니다. 허용하지 않으면 수집되지 않습니다.

2. 개인정보의 이용 목적

항목이용 목적
UUID저장·방문·후기 등 이용자별 데이터를 구분·연결하는 식별자 (그 자체로 개인을 특정하지 않음)
닉네임앱 내 이용자 식별, 후기 작성자 표시
저장한 매장·방문 기록개인 즐겨찾기, 원정 기록·업적 제공 (본인에게만 제공)
별점·한줄 후기다른 이용자에게 매장 정보를 공유하는 게시 콘텐츠
문의 내용고객 문의 응대
신고 내용부적절한 게시물 검토·조치
푸시 토큰공지사항, 문의 답변, 후기 알림 등 발송
IP 주소부정 이용 방지, 비정상 접근 차단, 법적 분쟁 대응 근거 자료

3. 정보 공개 범위

비공개 — 본인만 열람 가능

  • 저장한 매장 목록
  • 별점·후기를 남기지 않은 단순 방문 기록
  • 고객센터 문의·답변 내용
  • 신고 내용
  • 푸시 토큰

비공개 — 회사만 열람 가능(이용자 본인에게도 화면으로 표시되지 않음)

  • IP 주소

공개 — 다른 이용자가 열람 가능

  • 닉네임
  • 매장에 남긴 별점 및 한줄 후기, 작성일
  • 누적 후기 수를 기준으로 한 등급/칭호 표시
  • 달성한 업적 목록 (원정대원 프로필 화면)
닉네임, 후기, 업적은 앱을 사용하는 다른 모든 이용자에게 공개되는 정보입니다.
후기에는 전화번호, 이메일, 주소 등 본인 또는 제3자의 개인정보를 작성하지 말아 주세요.

4. 보유 및 이용 기간

앱을 삭제해도 클라우드에 저장된 데이터(닉네임·저장·방문·후기 등)는 자동으로 삭제되지 않습니다.

설정 화면의 "초기화" 기능은 기기에 저장된 기록만 삭제하며, 클라우드에 이미 저장된 데이터는 함께 삭제되지 않습니다.

현재 앱 내에는 계정 전체를 삭제하는 기능이 별도로 제공되지 않습니다. 저장된 정보의 삭제를 원하시면 아래 문의처로 요청해 주시면 확인 후 처리해 드립니다.

5. 개인정보의 국외 처리 관련 안내

서비스는 사용자 인증·데이터 저장을 위해 Supabase를, 오류 리포팅을 위해 Sentry를 이용하고 있으며, 두 서비스 모두 해외 사업자입니다. 이 과정에서 이용자 정보의 전부 또는 일부가 국외에서 처리·보관될 수 있습니다. 위탁 현황 및 처리 지역에 변경이 있는 경우 본 방침을 통해 고지합니다.

6. 이용하는 외부 서비스

  • 네이버지도(NAVER Maps) SDK — 지도 표시
  • 네이버지도·카카오맵·티맵 — 길찾기(이용자가 선택한 경우에만 연동)
  • Supabase — 사용자 인증 및 데이터 저장
  • Sentry — 오류(크래시) 리포팅

7. 위치정보

앱 설치 시 위치 권한을 자동으로 요청하지 않으며, "내 주변" 기능을 처음 사용할 때만 권한을 요청합니다.
